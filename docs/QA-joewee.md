# QA pass: Joewee’s screens (J13)

A full QA pass of the Market Lab, Coach, Create, block explorer, Future You, Piggy Bank, Farm, Orchard, Daily Stall, Bank and Cow Fair, on 16 October 2026. Every screen was tested at all three levels (Explorer, Trader, Builder) and at 360 px and 1440 px in headless Edge, served with the production CSP.

How it ran: one finder per screen group drove the real UI with mouse, keyboard and touch-size viewports, then a second, independent agent tried to reproduce every finding from scratch and either confirmed it (with a root cause and a fix plan) or rejected it. Fixes were made per file group in separate git worktrees, then checked again by another independent agent, with one more round for anything that came back.

Totals: 188 findings. 177 fixed, 0 still open, 4 not a bug, 7 in Yotha’s files. Confirmed by severity: 1 blocker, 20 major, 94 minor, 69 polish.
